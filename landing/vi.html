Cách hoạt động

Từ lúc cài đặt tới một đội agent làm việc, chỉ ba bước.

Không tạo thêm tài khoản AI, không dán key — Devdy dựa trên chính các login và công cụ bạn đang dùng.

  1. 1Đăng nhập

    Giữ nguyên login sẵn có

    Devdy điều khiển claude và codex CLI mà bạn đã đăng nhập sẵn — gói Claude và tài khoản ChatGPT của bạn.

    $ claude ✓ gói Claude $ codex ✓ login ChatGPT ai_api_key — không có —
  2. 2Thiết lập

    Thêm project, gắn tài khoản

    Chỉ cho Devdy một thư mục, app tự nhận diện các repo bên trong. Gắn tài khoản GitHub, GitLab hay AWS mà từng project cần dùng, rồi áp dụng Skill, Rule và MCP server.

    demo-app/ ├ github → work ├ skills → claude + codex └ mcp → đã bật
  3. 3Giao việc

    Giao một mục tiêu

    Tải về một issue hay PR, hoặc chỉ cần mô tả điều bạn muốn. Phiên tự lên kế hoạch, sinh worker khi việc lớn, và chỉ dừng lại hỏi bạn ở những quyết định quan trọng.

    goal Ra mắt checkout v2 → spawn implementer · reviewer · qa ⏸ chờ bạn phê duyệt
Hai engine, một chỗ

Claude và Codex, trong cùng một app.

Đặt engine và model mặc định, rồi đổi riêng cho từng lần chạy khi cần — thao tác và lịch sử vẫn y như nhau. Bạn dùng chính gói subscription sẵn có, không cần AI API key.

Claude

Dùng gói Claude của bạn

Đăng nhập claude CLI bằng tài khoản Claude. Chọn opus, sonnet hay haiku tuỳ tác vụ — thêm nhiều tài khoản Claude và Devdy có thể tự cân bằng tài khoản mặc định theo usage thực tế.

devdy một giao diện chung

Cùng một cách chạy, cùng một lịch sử, cùng một cách cấp quyền — dù bạn chọn engine nào.

Đăng nhập codex CLI bằng ChatGPT. Đổi qua lại với Claude mà không phải học lại gì.

Điều phối đa agent

Đưa một mục tiêu. Conductor lo cả đội.

Mọi phiên đều có thể làm conductor: chia việc lớn thành các vai — implementer, reviewer, QA — sinh các phiên worker chạy song song, đọc kết quả và lặp lại tới khi đạt mục tiêu. Bạn chỉ cần vào cuộc ở những điểm quyết định quan trọng.

Theo dõi trực tiếp

Nhìn mọi worker trong một màn

Worker được nhóm dưới conductor của nó trong History và dock run đang chạy, sắp theo hoạt động mới nhất, mỗi worker gắn nhãn tài khoản và model đang dùng.

Tự chạy, nhưng không mất kiểm soát

Conductor tự làm tiếp và chỉ quay lại hỏi bạn khi thật sự cần bạn quyết định.

  • Tự chạy tiếp. Conductor tiếp tục ngay khi một worker xong — không cần hỏi vòng, không cần canh chừng.
  • Mở rộng dễ dàng. Mặc định 10 worker song song, chỉnh được tới 100, kết hợp cả Claude lẫn Codex.
  • Cấp quyền rõ ràng. Cửa sổ xin quyền ghi rõ worker nào đang hỏi, yêu cầu bị lỡ cũng được khôi phục.
  • Mở tại chỗ. Vào bất kỳ worker nào, đọc transcript hay gửi thêm yêu cầu trong khi panel vẫn cập nhật trực tiếp.
Trong một app

Quản lý ngữ cảnh AI cho mọi project.

Skill, Rule và MCP server nằm ở một kho trung tâm, được áp dụng vào từng project — Devdy báo ngay khi bản trong project bị sửa lệch. Rồi dùng chính ngữ cảnh đó cho issue, PR và các phiên làm việc tự do.

01 · Skill · Rule

Soạn một lần, đồng bộ khắp nơi

Soạn Skill hay Rule một lần (hoặc gom thành nhóm), chọn áp dụng cho Claude, Codex hoặc cả hai, rồi đưa vào nhiều project. Sửa bản gốc là các project đồng bộ theo; nếu bản trong project đã bị sửa tay, Devdy báo xung đột để bạn chọn: dùng bản gốc, giữ bản local, hoặc tự viết bản riêng.

.claude/.codex/AGENTS.md
02 · MCP server

Một kho MCP, bật theo từng project

Khai báo server một lần, test bằng handshake MCP thật, rồi bật cho từng project — Devdy tự gắn vào các run của project đó. Secret trong env và header nằm trong Keychain; cấu hình import/export dạng JSON. Server SSE chỉ dùng được với Claude; Codex dùng stdio và HTTP.

stdioHTTPSSE · Claudetest kết nối
03 · Phân tích issue

Issue → kế hoạch chi tiết

Dán số hoặc URL issue — GitHub hay GitLab. Devdy tự lấy nội dung và thảo luận (bỏ qua bot), rồi phân tích thành kế hoạch chi tiết theo đúng Skill và Rule đã áp dụng cho project.

04 · Review PR / MR

Review PR và MR

Tải PR GitHub hoặc MR GitLab bằng số hay URL. Devdy gom diff và các review sẵn có — kèm issue liên kết nếu là GitHub — rồi review theo đúng quy ước của bạn.

05 · Phiên tự do

Phiên làm việc tự do

Trò chuyện nhiều lượt trong project: @mention file, kéo thả file hay ảnh, đính kèm note và todo, dùng lại prompt đã lưu, nhảy giữa các prompt trong phiên dài và tiếp tục phiên đã xong.

06 · Trung tâm cấp quyền

Duyệt khi đã thấy đủ ngữ cảnh

Xem diff trước khi lệnh Edit hay Write được ghi, trả lời câu hỏi trắc nghiệm của agent, duyệt kế hoạch trước khi nó bắt đầu, và tách yêu cầu cấp quyền ra cửa sổ riêng. Chọn chế độ cho từng lần chạy — hỏi (mặc định), tự chấp nhận chỉnh sửa, chỉ lập kế hoạch hoặc bỏ qua — và lưu quyết định "luôn cho phép" theo từng project.

xem diffAskUserQuestionduyệt kế hoạchcửa sổ rời
07 · Thống kê

Thống kê token & chi phí

Token và chi phí theo engine, project, model (tính cả subagent) và theo ngày, kèm usage thực của gói cho từng tài khoản Claude và gói Codex. Xoá run cũ vẫn không mất số liệu.

Tool có sẵn cho agent

Agent không chỉ trả lời — nó còn thao tác được trong Devdy.

Devdy có các MCP server tích hợp sẵn — tổng cộng 88 tool. Khi được bật, Devdy MCP (48 tool) được gắn vào từng phiên; Google MCP bổ sung 40 tool sau khi bạn kết nối Google OAuth. Mọi thao tác đều tuân theo chế độ cấp quyền bạn đặt cho phiên đó.

Cả ngày làm việc, ngay cạnh agent

Mail, lịch, Slack, server — một cửa sổ.

Devdy kết nối các công cụ bạn đang dùng và trao chúng cho agent — một phiên có thể đọc thread Slack, xem lịch hay SSH vào staging mà bạn không phải copy-paste gì, theo đúng chế độ cấp quyền của lần chạy đó.

Google

Gmail, Drive & Calendar

Kết nối một hoặc nhiều tài khoản Google bằng OAuth credential (Desktop app) của chính bạn. Màn lịch hợp nhất (có âm lịch) cho phép tạo và sửa sự kiện; agent có thể tìm mail, tải file đính kèm và làm việc với file trên Drive.

Ghi nhanh note và todo ở bất kỳ đâu trong app, tách ra cửa sổ riêng, gắn vào phiên và chèn vào prompt. Agent cũng đọc và cập nhật được.

Đa tài khoản & bảo vệ usage

Đủ mọi tài khoản. Đúng tài khoản cho từng project.

Thêm bao nhiêu tài khoản Claude, GitHub, GitLab, AWS và Google tuỳ ý rồi gắn theo từng project — repo công ty dùng tài khoản công ty, dự án riêng dùng tài khoản cá nhân. Devdy phân bổ usage Claude giữa các tài khoản và chặn run mới trước khi bạn chạm hạn mức của gói.

Không bao giờ vượt hạn mức của gói

GitHub · GitLab

Mỗi project một tài khoản

Nhiều tài khoản GitHub và GitLab (kể cả GitLab tự host), có kiểm tra quyền token. Run của project nào chỉ dùng đúng tài khoản gắn với project đó cho gh, glab và git — không đụng tới login global của bạn.

AWS

Access key hoặc SSO, theo project

Thêm tài khoản từ access key, profile trong ~/.aws hoặc chọn qua SSO. Tài khoản được gắn sẽ được cấp cho lệnh aws và làm mới giữa phiên; run không thể tự sửa credential.

Google

Công việc và cá nhân, song song

Kết nối nhiều tài khoản Google bằng OAuth credential của chính bạn; agent chọn đúng tài khoản cho từng lệnh (hoặc dùng mặc định). Refresh token nằm trong Keychain, còn thao tác gửi, chia sẻ, xoá đi qua bước xin quyền ở chế độ Hỏi.

Menu bar, cửa sổ rời & thông báo

Devdy ở yên một góc cho tới khi bạn cần.

  • Chuyển nhanh từ menu bar. Xem số phiên đang chạy và nhảy tới bất kỳ phiên nào ngay từ tray.
  • Cửa sổ rời. Phiên, todo, note và yêu cầu xin quyền đều tách được ra cửa sổ riêng.
  • Thông báo hệ thống. Biết ngay khi phiên chạy nền xong hoặc cần bạn duyệt.
  • Tuỳ biến theo ý bạn. Theme sáng / tối, cảnh nền theo mùa lễ, giao diện tiếng Anh / tiếng Việt và linh vật Cyber Fox tuỳ chọn.
Local-first & bảo mật

Mọi thứ Devdy lưu đều nằm trên máy bạn.

  • Không cần AI API key. Claude và Codex xác thực bằng chính login của claude / codex CLI bạn đang dùng.
  • Secret chỉ nằm trong Keychain. Token GitHub/GitLab, credential MCP, đăng nhập Google và passphrase server chỉ nằm trong OS Keychain — không bao giờ ghi ra file, log hay môi trường của engine.
  • Credential broker theo từng run. Mỗi run chỉ nhận token của tài khoản gắn với project, khi cần, qua một lớp policy, phê duyệt và audit — và từ chối thay vì dùng tạm login global của bạn.
  • Không có cloud Devdy. Skill, rule, lịch sử và thống kê nằm trong SQLite và file log trên máy. Prompt chỉ gửi tới engine bạn chạy (Anthropic hoặc OpenAI), các dịch vụ đã kết nối như GitHub hay Google làm việc với API của chính họ, còn điều khiển từ xa đi qua relay tự host của bạn, mã hoá đầu-cuối.
  • Bạn chọn chế độ cấp quyền. Mặc định Devdy hỏi trước các thao tác công cụ nhạy cảm; với từng lần chạy bạn có thể chuyển sang tự chấp nhận chỉnh sửa, chỉ lập kế hoạch hoặc bỏ qua.
